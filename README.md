## Compatibility

This setup is designed and tested on:
- Voron Trident 
- Centauri Carbon
- OpenCentauri / COSMOS firmware

However, the adaptive bed mesh logic is fully compatible with standard Klipper setups.
- Adaptive Bed Mesh implemented via native Klipper macros (no KAMP required)

### Notes
The adaptive bed mesh logic is implemented using native Klipper macros and does NOT require KAMP or external plugins
